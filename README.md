# GameDemo — TLOU-style movement slice

Dark room, flashlight only, over-the-shoulder camera, cover / vault / ledge / crawl.

## Open

1. Unity Hub → **Open** → `C:\Users\Travis\Documents\Coding\Projects\GameDemo`
2. Editor version: **6000.0.38f1** (already on this PC)
3. Menu: **GameDemo → Build / Rebuild Demo Scene**
4. Press **Play**

## Controls

| Input | Action |
|---|---|
| WASD | Move |
| Mouse | Look |
| Shift | Sprint |
| Space / E | Jump · vault mid box · climb tall box |
| C | Crouch · peek over mid cover |
| Z / Ctrl | Prone |
| F | Flashlight toggle |
| Walk into box | Take cover (cling) |
| A / D in cover | Strafe · peek corners (camera swaps shoulder) |
| S in cover | Leave cover |
| Crawl tunnel | Auto prone + camera zoom |

## What's in the room

- **Tall box** — wall cover, corner peek, ledge climb on top
- **Mid box** — hip-high duck cover, peek over, vault over
- **Crawl structure** — tunnel; camera pulls in over-shoulder while crawling

## Honest scope note

This mirrors the *verbs* of The Last of Us movement (cover cling, peek, vault, ledge, crawl, OTS shoulder swap). Feel/polish (animation, sound, mantle curves, sticky cover edges) is the long game — say the word and we iterate on feel next.
